The **Kiwi Framework** is a web application development framework based on
the [Spring Framework](https://spring.io/projects/spring-framework).
It is the spiritual successor to the internal `WDW::API` library based on PERL Catalyst.

The Kiwi Framework was founded in 2024 by werdenktwas GmbH.
